libgame.so's 13 `Java_comSdk_IComSdk_*` exports are intentionally left undeclared on the Java side: no `comSdk` class exists in either stock APK's dex, so the stock build runs without them too, JNI binds such exports only when a Java `native` method of that name is declared, and the short-form symbol names carry no parameter types to recover — a `comSdk/ComSdkImpl` FindClass failure in logcat is the dead ComSDK channel, not a missing file (verified with jadx 1.5.6, 21-10-2026; detail in .superpowers/sdd/2026-10-20-plan-a-boot-to-main-city/task-5-report.md).
